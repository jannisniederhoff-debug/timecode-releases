# Timecode – Downloads

Fertige Versionen von **Timecode** (Pro DJ Link Monitor für Pioneer CDJ/XDJ/DJM).

## Herunterladen (Windows)

**[Timecode-Windows.zip](https://github.com/jannisniederhoff-debug/timecode-releases/raw/main/Timecode-Windows.zip)** –
entpacken, `Timecode starten.bat` doppelklicken. Anleitung: `LIESMICH.txt` im ZIP.

Bereits installierte Versionen aktualisieren sich automatisch
(„Update verfügbar“ oben rechts im Programm).

## Inhalt dieses Repos

| Datei | Zweck |
|---|---|
| `Timecode-Windows.zip` | Komplettpaket zum ersten Einrichten |
| `Timecode-<version>.exe` | Programmdatei für das automatische Update |
| `latest.json` | Versionsinfo, die das Programm alle 10 Minuten abfragt |
